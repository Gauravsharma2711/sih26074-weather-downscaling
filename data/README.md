# Data Storage Directory

This directory holds the multi-stage datasets for the SIH26074 weather downscaling pipeline:

- `raw/`: Immutable source datasets (e.g. `nashik_panchayat_weather_raw.csv`).
- `processed/`: Cleaned and standardized datasets and baseline benchmarks.
- `features/`: Engineered features for ML training and evaluation.
- `validation/`: Held-out ground truth evaluation splits and metrics.
